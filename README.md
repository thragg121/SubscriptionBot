# Subscription Bot — платний доступ до закритого Telegram-каналу

Демо: [@subscription2_demo_ua_bot](https://t.me/subscription2_demo_ua_bot)

Бот для тренерів, психологів, викладачів і авторів курсів, які продають доступ до закритого каналу.

## Що вміє
- **Тарифи** (1 / 3 / 12 місяців) і оплата. У демо оплата тестова; під клієнта підключається WayForPay, LiqPay або monobank.
- **Доступ одразу після оплати**: особисте посилання в канал на один вхід, діє 24 години.
- **Продовження** додає термін до поточної підписки; загублене посилання можна перевипустити.
- **Нагадування** за 3 дні до кінця.
- **Автоматичне закінчення**: після терміну бот прибирає людину з каналу й пропонує продовжити.
- **Панель власника** в боті: статистика (активні, дохід за 30 днів, у кого скоро закінчується), список підписників, зміна цін, розсилка активним / тим, у кого закінчилась / усім.
- Демо-тариф «3 хвилини», щоб побачити весь цикл.

## Стек
Python 3.12, aiogram 3, SQLAlchemy 2 (async) + SQLite/aiosqlite, фоновий планувальник на asyncio. Деплой — Railway (`Procfile`, worker).

## Запуск
```
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python main.py
```
Змінні середовища (`.env`):

| Змінна | Опис |
|---|---|
| `BOT_TOKEN` | токен від @BotFather |
| `CHANNEL_ID` | id закритого каналу (бот — адмін з правом запрошувати й видаляти учасників) |
| `ADMIN_IDS` | Telegram id власника(ів) через кому |
| `DEMO_MODE` | `1` — демо: тестова оплата, панель доступна всім відвідувачам |
| `DATABASE_URL` | за замовчуванням `sqlite+aiosqlite:///data/subscription.db` |
